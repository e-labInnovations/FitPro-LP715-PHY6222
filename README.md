# Hacking FitPro LP715/716 Watch - PHY6222

Reverse engineering and custom firmware development for the **FitPro LP715/716 Smartwatch**, which uses the **PHY6222** SoC.

The goal is to replace the stock firmware with a custom one for my new project.
